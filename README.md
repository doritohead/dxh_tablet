# DXH Tablet

DXH Tablet is a persistent tablet OS resource for QBCore FiveM servers.

## Status

Current build: Stage 1 Foundation

## Dependencies

- qb-core
- oxmysql

## Installation

1. Place `dxh_tablet` into your resources folder.
2. Import `sql.sql`.
3. Add the tablet item to your inventory system.
4. Add this to `server.cfg`:

```cfg
ensure dxh_tablet
