# 📱 DXH Tablet

A modern, fully custom tablet system for QBCore servers featuring multiple integrated applications, persistent data storage, light and dark mode support, and a unified Android-inspired user interface.

---

# 📱 Home Screen

The central hub of DXH Tablet, providing quick access to all applications, settings, and tablet functionality through a clean Android-inspired interface.

### ✨ Features

* Real-time clock & date
* Dynamic wallpaper system
* Light & Dark themes
* Quick app access
* Persistent user preferences
* Smooth UI animations
* Modern Android-inspired design

# 🃏 TCG Marketplace

The TCG Marketplace allows players to browse, buy, and sell trading cards directly from their tablet. Built specifically for integration with the upcoming DXH Trading Cards resource.

### ✨ Current Features

* Browse player listings
* Purchase cards
* Create card listings
* Search functionality
* Sort by card name
* Sort by price
* Filter by card set
* Listing notifications
* Light & Dark mode support

### 🔨 Planned Features

* Full DXH Trading Cards integration
* Recently sold listings
* Market statistics
* Wishlist system
* Seller profiles
* Price history tracking
* Favourite cards
